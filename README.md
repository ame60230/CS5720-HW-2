CS5720 Neural Network and Deep Learning

## Overview

This assignment covers recurrent neural networks, sentiment classification, convolution operations, CNN feature extraction, and CNN architectures using TensorFlow/Keras.

## Question 1 - RNN Text Generation

Trained an LSTM-based RNN using Shakespeare text to predict and generate characters. Different temperature values were also used to compare predictable and more random text generation.

## Question 2 - Sentiment Classification

Trained an LSTM model using the IMDB movie review dataset to classify reviews as positive or negative. Model performance was evaluated using accuracy, precision, recall, F1-score, and a confusion matrix.

## Question 3 - Convolution Operations

Applied a 3x3 kernel to a 5x5 input matrix using different stride and padding combinations and compared the resulting feature maps.

## Question 4 - CNN Feature Extraction

Used Sobel-X and Sobel-Y filters for edge detection and demonstrated both Max Pooling and Average Pooling on a 4x4 matrix.

## Question 5 - CNN Architectures

Implemented a simplified AlexNet architecture and a ResNet-like model using residual blocks and skip connections. Model summaries were generated for both architectures.
